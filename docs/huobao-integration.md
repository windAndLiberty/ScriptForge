## 架构映射

| Huobao Drama | 剧擎对齐实现 | 说明 |
|---|---|---|
| Mastra Agent 工厂 | 有明确职责和结构化契约的阶段 Agent | 角色命名、事实抽取、圣经架构、分集规划、逐集编剧、连续性编辑 |
| Agent Tools 读写数据库 | 强类型中间资产 | 每个阶段只读取上游资产、返回可校验的 JSON 资产 |
| `script_rewriter` | `episode_writer` | 不做小说压缩，依据故事圣经和分集执行契约写可拍场景 |
| `extractor` | `story_bible_architect` | 合并人物别名、关系、世界规则、时间线和道具生命周期 |
| `characters` / `scenes` 去重 | Canonical ID + 转场因果 | 改编名只做显示，人物关联始终使用稳定 ID |
| Agent Skill | 可编辑提示词资产 | 新增“全剧事实圣经”资产，继续支持中英文界面与恢复默认 |
| 任务状态 | 显式管线阶段 | 增加“全剧圣经”阶段和可视化结果页 |

## 剧擎增强点

上游项目主要服务剧本到分镜、图片、视频的生产流程；剧擎继续聚焦
“长篇小说到中国竖屏短剧剧本”，并在其前面增加：

1. 人物实体消歧，阻止同一人物跨集突然改名。
2. 世界规则唯一事实源，区分状态、原因和证据。
3. 时间线事件的地点、前因、结果，阻止无交代转场。
4. 相邻集核心冲突去重，避免连续多集重复退婚或羞辱。
5. 道具/伏笔的引入、状态和兑现集追踪。
6. 以对白、停顿、表演动作、转场共同计算可拍时长。
7. 故事圣经和分集契约失败时先定向修复，再进入逐集成稿。

## 60 秒规格

- 场次数由模型在 1–3 场间按剧情决定，推荐值只用于离线模式。
- 12–18 句有效对白。
- 约 129–195 个对白汉字，目标约 162 字。
- 单句尽量不超过 15 字，程序标记超过 18 字的长台词。
- 时长估算同时计入语速、标点停顿、演员反应、动作节点与场间转场。
