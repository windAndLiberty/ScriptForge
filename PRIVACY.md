# ScriptForge Privacy Policy / ScriptForge 隐私政策

**Effective date / 生效日期：August 27, 2026 / 2026 年 8 月 27 日**

ScriptForge is developed by Shenzhen Yu Se Technology Co., Ltd. This policy explains how the macOS application handles user data.

ScriptForge 由 Shenzhen Yu Se Technology Co., Ltd. 开发。本政策说明 macOS 应用如何处理用户数据。

## Data Collection / 数据收集

ScriptForge does not collect, store, sell, or share personal information, usage analytics, advertising identifiers, device identifiers, or diagnostic data. The application does not require an account or login.

ScriptForge 不收集、存储、出售或共享个人信息、使用分析数据、广告标识符、设备标识符或诊断数据。应用不要求用户注册账号或登录。

## Local Data Storage / 本地数据存储

Projects, imported documents, chapter versions, prompts, settings, and generated materials are stored locally on the user's Mac. API credentials are stored in the macOS Keychain. The developer cannot access these credentials or the user's locally stored project content.

项目、导入的文档、章节版本、提示词、设置和生成内容均保存在用户的 Mac 本机。API 凭据存储在 macOS 钥匙串中。开发者无法访问这些凭据或用户在本机保存的项目内容。

## Optional AI Services / 可选 AI 服务

ScriptForge supports optional AI-assisted features through a Bring Your Own Key (BYOK) model. When the user explicitly runs an AI-assisted operation, only the content selected for that operation is sent directly from the user's Mac to the API endpoint configured by the user.

ScriptForge's developer does not receive, proxy, or store the user's documents, prompts, API credentials, requests, or generated results. Data handling by the user-selected API provider is governed by that provider's privacy policy and terms of service.

ScriptForge 通过用户自备密钥（BYOK）模式提供可选的 AI 辅助功能。只有当用户主动运行 AI 操作时，本次操作所选择的内容才会从用户的 Mac 直接发送至用户配置的 API 端点。

ScriptForge 开发者不会接收、中转或存储用户的文档、提示词、API 凭据、请求或生成结果。用户所选 API 服务商的数据处理行为受该服务商自身隐私政策及服务条款约束。

## Document Access / 文档访问

ScriptForge accesses only files that the user explicitly selects or drags into the application. Files are processed locally unless the user explicitly starts an optional AI-assisted operation.

ScriptForge 仅访问用户明确选择或拖入应用的文件。除非用户主动启动可选的 AI 辅助操作，否则文件只在本机处理。

## Tracking and Advertising / 追踪与广告

ScriptForge does not contain advertising, analytics, tracking technologies, or third-party advertising SDKs.

ScriptForge 不包含广告、分析、追踪技术或第三方广告 SDK。

## Data Deletion / 数据删除

Users can delete projects and related files from within the application or by removing ScriptForge's local application data from their Mac. Because the developer does not operate user accounts or collect project data, there is no server-side personal data to request or delete.

用户可以在应用内删除项目及相关文件，也可以从 Mac 上移除 ScriptForge 的本地应用数据。由于开发者不运营用户账号且不收集项目数据，因此不存在需要向开发者申请删除的服务器端个人数据。

## Changes to This Policy / 政策变更

This privacy policy may be updated when ScriptForge's features or data practices change. The effective date at the top of this page will be updated accordingly.

当 ScriptForge 的功能或数据处理方式发生变化时，本隐私政策可能会更新，页面顶部的生效日期也会相应调整。
